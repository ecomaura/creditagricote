# Credit Agricote website

Static single-page site (HTML + CSS + a little JS). No build step.

- `index.html` – the full site
- `assets/logo.jpg` – brand logo

Deploy with GitHub Pages: Settings > Pages > Deploy from branch > `main` / root.

Before launch, consider adding: your registration details (e.g. AMFI ARN, IRDAI/RBI-related registrations as applicable) in the footer, a privacy policy, and your office address.
